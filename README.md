## The line

> Kid, the scar on your left knee will outlive every trophy on your shelf — wear shorts, it's the only honest thing you own.

## How it works

`main.py` (Python stdlib only) writes exactly that one line to `/output/entry.txt`, with no trailing newline. It asserts the line is a single line of 1–200 characters with no leading or trailing whitespace, so the entry always passes the kit's gate. Two runs produce byte-identical output.

Run it locally with:

```sh
OUTPUT_PATH=/tmp/out/entry.txt python3 main.py
```
